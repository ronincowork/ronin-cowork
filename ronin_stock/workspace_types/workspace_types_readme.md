# Workspace types and variants

One file per project type and per variant, listed by the new-workspace behaviour
(`ronin-help new-workspace`). A file of your own in `~/ronin/custom/workspace_types/` adds a type or
variant, or replaces a stock one by name, under the one rule
([stock_readme.md](../stock_readme.md#three-places-each-with-one-meaning)). Nothing else needs changing.

    # Title
    - **kind:** type | variant
    - **for:** who or what it is for, a few words
    - **order:** 10

    What the Workspace gets, or the choices it offers: one or two sentences.
