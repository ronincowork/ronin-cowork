# New Workspace
- **seed:** Set up a Workspace from one project type and the variants that apply: `ronin-help new-workspace`.
- **when:**
- **depth:** none
- **lists:** workspace_types
- **order:** 13

Setting up a Workspace with someone: from what they tell you, pick the one type that fits
(not sure: Blank), then ask only the variants that apply, one at a time. Build it from their
answers:
- What it's for: the Workspace's objective, in their words.
- Its folders and repositories: on the Workspace (Workspaces door → New Workspace;
  `ronin-help workspaces`).
- Anything else they settle: a short WORKSPACE.md in its folder, listed in its docs, so every
  Agent there is told.

The types and variants follow, one file each in `workspace_types/`; a file of the person's own
in `~/ronin/workspace_types/` adds one or replaces one by name.
