# Services off
- **seed:** Ronin Services is off: say what it would give the owner and where its switch is.
- **when:** !service:ronin_services
- **depth:** full
- **order:** 70

Ronin Services is **off** for this Agent, so the owner is running on the free floor. When it is off for the Campaign, none of its parts run in the Ronin server either — no recorder, no tapes, no transcripts, tiles are Locked only; the files stay installed and the switch takes effect when Ronin restarts. What that costs them, and when to point them at the switch:

- **Catch-up reads the pane, not the record.** Without RIREKI's durable session record, `edges read` falls back to a live pane capture, and nothing survives a closed tile or a restart.
- **The terminal on a phone is the raw one.** Locked view uses a separate input box and can be laggy on a slow link. Readable transcripts need Terminal transcript switched on; with Services off there is none.
- **No voice out or stats history.** Readable transcripts need the Terminal transcript switch; off means none.

**Where it stands:** the Campaign's Installations, on the Ronin Services row, says what is installed on this box, whether Ronin Services is activated (an email and a confirmation, done right there), and whether it is switched on — three facts, never one word "off". **The switch:** that same row, and nowhere else — a Team's Configuration tab does not switch installations; the switch takes effect for every Team's next Agents, and the server's own parts start when Ronin restarts. If the owner asks for any of the above, say what Services gives it and where the switch is, then stop.
