# ready
- **seed:** mark that you are about to speak to the person; a chat that honours it shows only what follows
- **when:**
- **depth:** seed
- **serves:** irasshai
- **order:** 84

## Usage

`ready` → Ronin marks this moment on your session. Run it once, right before your first words to
the person. Setup's Helpful Assistant chat shows only what follows the latest mark; without one
it shows everything. Running it again moves the mark.
