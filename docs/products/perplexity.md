# Perplexity connection

Perplexity is a planned connection for selected Agents to use Perplexity for research
through a dedicated Behavior. It is not available yet and cannot be enabled.

When the connection becomes available, Setup will explain what access it requests, how to
connect an account, and how to choose which Agents receive the Behavior. Until then, the
Coming soon marker is the complete status: there is nothing to configure.
