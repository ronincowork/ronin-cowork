# Draft a plan

Use this way of working when the goal is known but the implementation needs to be
thought through. Its remit is to write a plan for the work without beginning the work
itself.

The Agent verifies the ground it is planning against and distinguishes evidence from
assumption. It agrees the goal in your words, writes the build-out document with the
constraints and proof of completion, and stops for review. Questions and decisions come
back to you rather than being silently guessed. The plan is the whole output; code and
implementation commits belong to a later step.
