# RONIN BASE — what this Agent is working without

Ronin Base is **off** for this Agent: no `+name:` macros, no team board, no work record the owner can read on the tile, no `tejun-send` to another session. The owner talks to each Agent one at a time and carries every message between them.

Base gives the ordinary house: macros, the wipeboard, work records and session-to-session messages.

**The switch:** Team Configuration for this team, or the Campaign's Routines for new teams.
