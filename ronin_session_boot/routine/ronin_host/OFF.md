# RONIN HOST — what this Agent is working without

Ronin Host is **off** for this Agent. Questions about the machine — disk, memory, who this install runs as, where a store lives, whether the session engine is healthy — have no measured answer here; anything said about the box is a guess.

Host gives `tejun-survey`, `tejun-account` and the machine SOPs: install checks, accounts, network reach, health, the session engine.

**The switch:** Team Configuration for this team, or the Campaign's Routines for new teams. If the owner asks what the box is or why it is slow, this is the Routine.
