# mcp_on — the shelf a CONNECTED session reads

Ships **empty on purpose**, and this file is here so the level survives a clone: git does
not track an empty directory, so without a file in it `mcp_on/` exists on the box that made
it and on no other. Three documents name this level (`docs/session-boot.md`,
`ronin_sops/gbrain.md`), and a level that is only a claim is worse than no level.

**What it is.** A session launched with MCP **on** reads this shelf; a session launched with
MCP **off** reads neither the connectors nor this. That is the owner's ruling of
2026-08-17: the launch toggle governs both halves of a connection, so a session that cannot
reach the brain is not handed a page about using it.

**Why cowork ships it empty.** The level is core; what sits on it is the services' business
— the gbrain service seeds its own reading here. Cowork naming a connector's documents
would put a vendor in the free build, which is the line the whole split exists to hold.

Your own half is a store outside every repo (`ronin-store session_boot` → `mcp_on/`); a
file of yours with the same name replaces ours whole, a new name sits beside it.
