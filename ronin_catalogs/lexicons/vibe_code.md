# vibe_code

The game lobby's words. Deliberately short while the surfaces are still moving — what
is not said here falls through to `professional`, and the words grow as surfaces settle.

- **label:** Vibe code
- **blurb:** The lobby's words — campaigns, squads, loadouts.
- **base:** professional
- **squad:** Squad
- **player_one:** Player One
- **team_kit:** Team kit
- **loadout:** Loadout
